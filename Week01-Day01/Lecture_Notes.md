## 학습 목표

- 동적 계획법(DP)이 필요한 상황을 설명한다.
- 중복 부분 문제와 최적 부분 구조를 구분한다.
- Memoization과 Tabulation으로 피보나치 수열을 구현한다.
- 마지막 선택을 기준으로 계단 오르기 점화식을 만든다.

## DP 핵심 개념

동적 계획법은 이미 계산한 작은 문제의 결과를 저장하고 다시 사용해 중복 계산을 줄이는 방법이다. 다음 두 조건이 함께 나타날 때 DP 적용을 고려한다.

1. 최적 부분 구조: 작은 문제의 답을 조합해 큰 문제의 답을 만들 수 있다.
2. 중복 부분 문제: 같은 작은 문제가 여러 번 반복해서 등장한다.

피보나치 수열은 `F(n) = F(n-1) + F(n-2)`라는 점화식으로 표현된다. 단순 재귀는 동일한 `F(k)`를 반복 호출하지만, DP는 계산 결과를 저장해 각 상태를 한 번만 계산한다.

| 방식 | 진행 방향 | 저장 방식 | 특징 |
| --- | --- | --- | --- |
| 단순 재귀 | 큰 문제에서 작은 문제로 이동 | 없음 | 구현은 간단하지만 중복 호출이 많다. |
| Memoization | Top-down | 딕셔너리 또는 배열 | 필요한 상태만 재귀적으로 계산한다. |
| Tabulation | Bottom-up | `dp` 테이블 | 작은 상태부터 순서대로 채운다. |

## 피보나치 문제 풀이 흐름

1. `n <= 1`과 같은 종료 조건을 정한다.
2. 현재 상태를 더 작은 상태의 조합으로 표현한다.
3. 계산된 값이 저장되어 있는지 먼저 확인한다.
4. 저장된 값이 없다면 계산한 뒤 기록한다.
5. 일반 재귀, Memoization, Tabulation의 호출 횟수와 저장 공간을 비교한다.

단순 재귀의 시간 복잡도는 지수적으로 증가하지만, Memoization과 Tabulation은 각 상태를 한 번씩 계산하므로 일반적으로 `O(n)`에 해결할 수 있다.

## 계단 오르기

한 번에 1칸 또는 2칸을 오를 수 있다면 `n`번째 계단에 도착하는 마지막 이동은 다음 두 경우로 나뉜다.

```text
dp[n] = dp[n - 1] + dp[n - 2]
```

- `dp[1] = 1`
- `dp[2] = 2`

1칸, 2칸, 3칸을 모두 허용하면 다음처럼 확장된다.

```text
dp[n] = dp[n - 1] + dp[n - 2] + dp[n - 3]
```

이때 `dp[0] = 1`을 두면 출발 위치를 하나의 유효한 경우로 처리할 수 있다.
