- 웹 서비스를 운영 환경으로 옮길 때 필요한 항목을 점검한다.

## 배포와 운영 환경

배포는 개발한 서비스를 사용자가 접근할 수 있는 환경에 올리는 과정이다. 로컬에서 동작하는 코드라도 운영 서버에서는 주소, 포트, 설정, 정적 파일, 데이터, 로그와 보안을 별도로 준비해야 한다.

| 구분 | 개발 환경 | 운영 환경 |
| --- | --- | --- |
| 목적 | 구현과 빠른 확인 | 실제 사용자에게 안정적인 서비스 제공 |
| 주소 | `localhost` 중심 | 서버 IP 또는 도메인 |
| 설정 | 개발 편의 중심 | 보안, 성능과 장애 대응 중심 |
| 데이터 | 테스트 데이터 | 보호와 백업이 필요한 실제 데이터 |
| 로그 | 개발자 직접 확인 | 지속적인 기록과 모니터링 필요 |

## VMware Workstation 설치

강의자료의 설치 흐름은 다음과 같다.

1. VMware Workstation 공식 다운로드 페이지로 이동한다.
2. Broadcom 계정으로 로그인하거나 계정을 만든다.
3. 무료 소프트웨어 다운로드 메뉴에서 VMware Workstation Pro를 찾는다.
4. 17 버전과 Windows용 설치 파일을 선택한다.
5. 이용 약관에 동의하고 설치 파일을 실행한다.
6. 설치 옵션과 바로가기를 확인한 뒤 설치를 완료한다.
7. VMware Workstation이 정상적으로 실행되는지 확인한다.

웹사이트 화면과 배포 정책은 변경될 수 있으므로 실제 설치 시에는 공식 안내를 기준으로 한다.

## Rocky Linux 가상머신 생성

이 저장소의 실제 실습 환경은 `Rocky Linux 9.8 Minimal`이다.

1. Rocky Linux 설치 ISO를 준비한다.
2. VMware에서 `Create a New Virtual Machine`을 선택한다.
3. Installer disc image에 ISO 파일을 지정한다.
4. Guest OS는 Linux, 버전은 Red Hat 계열 64-bit로 설정한다.
5. 가상머신 이름과 저장 위치를 정한다.
6. 가상 디스크 크기와 파일 저장 방식을 설정한다.
7. 가상머신을 생성하고 부팅한다.
8. 설치 미디어 검사를 거쳐 Rocky Linux 설치 화면으로 진입한다.
9. 설치 대상 디스크와 필요한 계정 및 네트워크 설정을 확인한다.
10. 설치를 진행하고 재부팅 후 로그인 화면을 확인한다.

Minimal 이미지는 GUI 도구가 적으므로 서버 운영에 필요한 패키지만 명확히 설치하고 네트워크 상태를 먼저 점검해야 한다.

## 배포 준비 체크리스트

### 주소와 네트워크

- 서버 IP, 포트와 접근 경로 확인
- 방화벽에서 필요한 포트만 허용
- 외부 접속 가능 여부 확인

### 설정

- 개발용 설정과 운영용 설정 분리
- 비밀값을 소스가 아닌 환경변수로 관리
- 허용 호스트, 디버그 모드와 보안 설정 확인

### 파일과 데이터

- 애플리케이션 코드와 의존성 설치
- 정적 파일과 업로드 파일 경로 구분
- 데이터베이스 연결과 백업 정책 확인

### 실행과 검증

- 서비스 프로세스가 정상 실행되는지 확인
- 요청과 오류 로그 기록
- 주요 화면과 API를 운영 주소에서 다시 테스트
- 장애 시 재시작과 복구 절차 기록

## 핵심 정리

- 배포는 파일 복사만이 아니라 운영 환경의 주소, 설정, 파일, 데이터와 로그를 함께 구성하는 작업이다.
- 가상머신은 호스트 OS와 분리된 Linux 서버 실습 환경을 제공한다.
- 설치 후에는 네트워크와 접속 상태를 먼저 확인한다.
- 운영 비밀값과 개발 설정을 코드에서 분리한다.
- 배포 완료 여부는 실제 운영 주소에서 기능과 로그를 확인해 판단한다.
