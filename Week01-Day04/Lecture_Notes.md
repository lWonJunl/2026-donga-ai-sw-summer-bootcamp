# Week 01 Day 04 - Dijkstra Algorithm

> 원본 강의자료: `week01day04.pdf` (29쪽)

## 학습 목표

- Stack, Queue, Heap의 원소 선택 기준을 비교한다.
- 다익스트라 알고리즘의 적용 조건을 설명한다.
- 인접 리스트와 최소 힙으로 최단 거리를 계산한다.
- 이전 정점 정보를 이용해 실제 이동 경로를 복원한다.

## 자료구조 선택

| 자료구조 | 꺼내는 기준 | 대표 활용 |
| --- | --- | --- |
| Stack | 마지막에 넣은 값 | DFS |
| Queue | 먼저 넣은 값 | BFS |
| Min-Heap | 우선순위가 가장 작은 값 | Dijkstra |
| List | 위치 기반 접근 | 순서가 있는 데이터 |
| Dictionary | 키 기반 접근 | 정점별 거리와 이전 정점 저장 |

다익스트라는 아직 확정되지 않은 후보 중 누적 거리가 가장 짧은 정점을 반복해서 선택하므로 최소 힙이 적합하다.

## 적용 조건

- 간선에 가중치가 있는 그래프
- 모든 간선 가중치가 0 이상인 그래프
- 하나의 시작점에서 다른 정점까지 최단 거리를 구하는 문제

음수 가중치가 있으면 이미 확정한 최단 거리가 나중에 더 작아질 수 있으므로 다익스트라를 그대로 사용할 수 없다.

## 핵심 자료구조

- `graph[node]`: `(next_node, weight)` 목록을 가진 인접 리스트
- `distance[node]`: 시작점에서 해당 정점까지 알려진 최단 거리
- `heap`: `(누적 거리, 정점)` 후보를 저장하는 최소 힙
- `prev[node]`: 최단 경로에서 바로 이전 정점

## 알고리즘 흐름

1. 모든 거리를 무한대로 초기화한다.
2. 시작점 거리를 0으로 설정하고 힙에 넣는다.
3. 힙에서 누적 거리가 가장 작은 후보를 꺼낸다.
4. 이미 더 짧은 거리로 처리된 오래된 후보라면 건너뛴다.
5. 인접 정점까지의 새 거리 `current + weight`를 계산한다.
6. 새 거리가 더 짧으면 `distance`, `prev`, `heap`을 갱신한다.
7. 힙이 빌 때까지 반복한다.

인접 리스트와 최소 힙을 함께 사용하면 일반적으로 `O((V + E) log V)`에 처리할 수 있다.

## 경로 복원

목적지에서 `prev`를 따라 시작점까지 거꾸로 이동한 뒤 순서를 뒤집는다. 목적지에 도달할 수 없는 경우와 시작점 자체를 조회하는 경우도 별도로 처리해야 한다.

간선을 추가한 뒤에는 거리표와 복원 경로가 어떻게 달라지는지 비교해 갱신 로직을 검증한다.
